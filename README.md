# PLUS Izolacje - Inżynieria bez kompromisów.

Ekskluzywna, zjawiskowo-biznesowa strona wizytówkowa (Landing Page) wzbogacona o szeroki obszar doradczo-technologiczny dla firmy **PLUS Izolacje**. Cel najnowszej reimplementacji to podkreślenie pozycji Lidera poprzez "Luxury Dark Mode" - surową, ale bardzo bogatą formę, budującą absolutne rynkowe zaufanie.

## ✨ Premium Features (Motyw Antracyt & Złoto)

*   **Dark Mode Premium Design (Inżynieryjne 10/10):** Agresywne przejście na kolor Ciemnego Antracytu i Hebanu z akcentami szczotkowanego złota (`#D4AF37`) oddającymi najwyższą jakość wykonawczą. Połącznie klasycznej czcionki nagłówkowej (`Playfair Display`) w celu pokazania powagi, obok fontu ułatwiającego czytanie (`Inter`).
*   **Efekty Szkła (Glassmorphism):** Przyklejone, ciemne panele nawigacyjne wtapiające się bezinwazyjnie pod ciemne ekrany smartphonów zapewniając idealne pokrycie tła.
*   **Powolne Animacje Biznesowe:** Majestatyczne `Intersection Observer` z podniesionym czasem `transition`. Umiarkowany ruch, symbolizujący precyzję (Brak pośpiechu i chaosu wyłaniania sekcji we Frontendzie).
*   **Karty Eksperckie z Podstronami:** Odłączenie wiedzy specjalistycznej od strony Głównej. Tworzenie pełnoprawnych Landing Page'ów oddzielnie na `Wylewki`, `Pianę PUR` oraz `Styrobeton`. Powstał zalążek platformy eksperckiej w branży budowlanej.
*   **Wbudowany Luksusowy Kalkulator Wycen:** Szybki, mosiężny kalkulator symulujący potrzebne budżety. Skrypt logiki Vanilla JS.
*   **Wydajność:** Kod odchudzony z wtyczek typu Oxygen i WordPress - Czyste technologie Front Endu bez uzależnień (Dependencies).

## 🛠 Technologie (Tech Stack)

*   **HTML5:** Nowa architektura wielu podstron (`wylewki.html`, `piana-pur.html`, `styrobeton.html` dołączone do `index.html`) zwiększająca potencjał organiczny SEO (jedno H1 per strona i odnośniki w silose).
*   **CSS3:** Dark Theme - Zmienne z kolorami zgaszonego, głębokiego tła oraz szlachetnych kolorów mosiądzu. Modułowe `grid` dla kafelków z usługami. Zaktualizowana o nową kolorstykę powaga stylów.
*   **JavaScript (Vanilla JS):** Rozbudowana funkcjonalność suwaków, cieniowanie dynamiczne navbarów i płynne animowanie elementów.
*   **Vercel:** Plik rutujący `vercel.json` omijający błędy hostowania z ścieżkami podstron.

## 📁 Struktura Biznesowej Platformy

```text
├── index.html       # Serce platformy, Hero (Lead Generation) oraz panel sterowania kalkulatorem.
├── wylewki.html     # Centrum wiedzy betonowych wylewek maszynowych Mixokret.
├── piana-pur.html   # Ekspertyza termiczna: Piana otwarta i Zamkniętokomórkowa.
├── styrobeton.html  # Landing Page dla wyrównań obciążeniowych w trudnym budownictwie.
├── style.css        # Kompletny Dark Luxury Design System.
├── script.js        # Lekka logika JS odpowiedzialna za mobilne zamykanie Menu i kalkulator.
├── vercel.json      # Poprawka rutowania i ominięcie błędów produkcyjnych na Vercelu.
└── README.md        # Niniejsza, profesjonalna specyfikacja.
```

## 🚀 Jak uruchomić lokalnie dla weryfikacji estetycznej?

1. Sklonuj to repozytorium na swój lokalny komputer:
   ```bash
   git clone https://github.com/twoj-profil/plus-izolacje-redesign.git
   ```
2. Otwórz folder jako całość w (np. Visual Studio Code).
3. Wybierz w plikach "Open with Live Server" - podstrony płynnie połączą się za pomocą relatywnych ścieżek bez "404 Not Found". Kliknięcia z logo, bądź menu natychmiast zadziałają tak samo jak u Klienta w Google.
